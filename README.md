# GDG · Teachable Machine + Arduino

```bash
npm install
npm run dev      # abre http://localhost:5173 en Chrome o Edge
```

1. Sube `arduino/tono_serial/tono_serial.ino` a tu Arduino (buzzer en pin 8).
2. Pega la URL del modelo de Teachable Machine (Image Project) y pulsa "Cargar modelo y cámara".
3. Pulsa "Conectar Arduino" y elige el puerto.
